# 집에서 실행하는 얄리 숏폼 스튜디오

이 압축본은 Windows x64용 포터블 실행 번들입니다. 압축을 푼 뒤 루트에 있는
`YaliShortformStudio.exe`를 더블클릭하면 CMD 창 없이 백그라운드 서비스와 작업 화면이 시작됩니다.

## 실행

1. ZIP 파일을 원하는 폴더에 압축 해제합니다. 경로에 한글이나 공백이 있어도 됩니다.
2. `YaliShortformStudio.exe`를 실행합니다.
3. 브라우저가 열리지 않으면 `http://127.0.0.1:5173/`를 직접 엽니다.
4. 종료할 때는 `YaliShortformStudio.exe /stop`을 실행합니다.

포터블 번들에는 Python과 Node.js 실행 파일, 프론트엔드·렌더 워커 의존성이 포함되어 있어
Python이나 Node.js를 별도로 설치하지 않아도 기본 화면을 실행할 수 있습니다.

## Codex 구독 연동

Codex 구독 인증 정보는 압축본에 넣지 않습니다. 집 PC에서 Codex CLI를 설치하고 현재 ChatGPT
계정으로 로그인한 뒤 실행해야 대본·이미지 생성이 동작합니다. Codex CLI가 PATH에 없다면 앱의
LLM 설정에서 `CODEX_CLI_PATH`에 설치된 `codex.exe` 경로를 지정하세요.

이미 생성되어 있던 프로젝트와 미리보기 자산은 `storage`에 함께 들어 있습니다. 새 작업 중 생성된
프로젝트·이미지는 압축을 푼 폴더의 `storage`에 저장됩니다.

## 개발용 수정

이 번들은 실행·확인용입니다. 소스를 수정한 뒤 프론트엔드 번들을 다시 만들거나 테스트하려면
저장소의 README에 있는 개발 명령을 사용하세요. 다음 백업 때에는 GitHub 저장소의 최신 소스와
별도의 ZIP 번들을 다시 생성하면 됩니다.
