## 구현

- `attach_generated_cut_audio`를 추가했다.
- 생성 결과를 `assets/generated` 아래에 content hash 기반으로 저장한다.
- 컷의 `audio_asset_id`와 활성 `CutVersion.audio_asset_id`를 함께 갱신한다.
- 동일 컷·버전·콘텐츠를 다시 저장해도 asset이 중복되지 않는다.
- Windows MAX_PATH를 고려해 짧고 안정적인 파일명을 사용한다.
- 프로젝트 asset 미리듣기 경로가 `audio` asset도 허용하도록 확장했다.
- asset 목록 응답에 오디오 미리듣기 URL을 제공한다.
