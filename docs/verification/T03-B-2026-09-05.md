# T03-B 검증 기록

일자: 2026-09-05  
범위: TTSProvider 계약과 Edge TTS 어댑터

## 구현

- `TTSGenerationRequest`·`TTSGenerationResponse`·`TTSProvider`를 AI provider 경계에 추가했다.
- `Operation.GENERATE_TTS`를 추가해 작업 메타데이터에서 TTS 요청을 구분한다.
- `EdgeTTSProvider`를 추가했다.
  - UI의 속도 배율을 Edge TTS rate 문자열로 변환한다.
  - 0~1 볼륨을 Edge TTS 상대 볼륨으로 변환한다.
  - UI의 반음 pitch를 Edge TTS Hz 값으로 변환한다.
  - metadata 청크는 제외하고 audio 청크만 합친다.
  - 빈 텍스트·빈 목소리·빈 결과를 provider 오류로 구분한다.
- `edge-tts>=7,<8`을 런타임 의존성으로 고정하고 lock 파일을 갱신했다.

## 검증

- RED: TTS 타입이 없는 상태에서 신규 테스트 수집 실패를 확인했다.
- GREEN: `backend/tests/test_tts_provider.py` 2 passed
- fake stream으로 외부 네트워크 없이 provider 호출 인자와 반환 MP3 바이트를 검증했다.
- `uv lock`: 39개 패키지 해석 완료
