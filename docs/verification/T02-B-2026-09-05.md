# T02-B 검증 기록: 컷별 영상 설정 예외

검증일: 2026-09-05  
범위: 프로젝트 영상 설정을 상속하면서 선택한 컷에만 음성·자막 예외를 저장하고, 매니페스트에 해석 결과를 반영하는 흐름

## 확인한 동작

- `PUT /api/projects/{project_id}/cuts/{cut_id}/video-settings`가 변경 필드만 저장한다.
- 빈 객체를 보내면 해당 컷의 예외 설정을 초기화한다.
- 컷 예외는 프로젝트 기본값보다 우선하고, 다른 컷에는 영향을 주지 않는다.
- 프로젝트 기본값을 변경하면 컷에서 예외로 지정하지 않은 필드는 새 기본값을 상속한다.
- 자막 배경색 `null`을 명시하면 프로젝트에서 상속한 배경색을 컷 단위로 해제할 수 있다.
- 컷 설정이 달라지면 출력 매니페스트의 `output_variant_id`도 달라진다.
- 설정 화면에서 프로젝트 기본값과 컷 예외를 전환하고, sparse 저장·초기화를 수행한다.

```text
frontend\npm run unit

```

브라우저 전용 QA 플러그인은 현재 세션에서 사용할 수 없어 일반 Playwright 실행으로 대체했다. E2E는 프로젝트 기본 설정 저장과 컷 예외 저장·초기화, 요청 payload를 확인한다. 로컬 5173 포트가 이미 사용 중이어서 통합 E2E는 격리 포트로 재실행했으며, 테스트 종료 후 임시 검증 변경은 모두 원복했다.
