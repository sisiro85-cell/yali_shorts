## 구현

- `GET /api/jobs/{job_id}`를 추가했다.
- 기존 `JobStatusResponse`를 그대로 사용해 payload, 멱등성 키, 생성 시각 같은 내부 값을 노출하지 않는다.
- 존재하지 않는 작업은 기존 오류 계약인 `JOB_NOT_FOUND`(404)로 응답한다.
- 프런트 `apiClient.getJob(jobId)`를 추가했다.
