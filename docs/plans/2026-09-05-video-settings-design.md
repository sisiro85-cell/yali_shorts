# 영상 설정(음성·자막) 설계안

작성일: 2026-09-05  
상태: T02-B 컷별 예외 설정 UI·API 구현 완료

## 목표

디자인 단계에서 컷별 이미지만 확인하는 데 그치지 않고, 최종 숏폼·릴스·카드뉴스에 적용될 음성(TTS)과 자막 표현을 확인하고 저장할 수 있게 한다.

핵심 원칙은 다음과 같다.

- 프로젝트 전체에 적용되는 기본 설정을 먼저 제공한다.
- 특정 컷만 다르게 만들 수 있도록 컷별 예외 설정을 제공한다.
- 출력 미리보기는 실제 출력 비율을 유지하고 원본 이미지를 임의로 잘라내지 않는다.
- Codex MCP는 대본 분석과 이미지 생성에 사용하며, TTS는 독립적인 엔진 어댑터로 연결한다.
- 설정 변경은 저장 후 출력 매니페스트와 렌더 작업에 동일하게 반영한다.

화면 구성:

2. 왼쪽에는 선택한 컷의 실제 출력 비율 미리보기를 표시한다.

4. 오른쪽에는 영상 설정 패널을 배치한다.
5. 패널은 음성 설정과 자막 설정 탭을 사용한다.
6. 하단에는 현재 컷에만 적용, 전체 컷에 적용, 설정 저장을 배치한다.
7. 620px 이하에서는 미리보기와 설정 패널을 세로로 쌓고, 하단 작업 버튼을 두 줄로 재배치한다.

## 설정 범위

### 음성 설정

- TTS 사용 여부
- 음성 엔진
- 언어·목소리
- 말하기 속도
- 음성 볼륨
- 선택 컷 음성 미리듣기
- 추후 피치와 배경 음악을 확장할 수 있는 구조

초기 실제 지원 후보는 Edge TTS와 오디오 파일 직접 사용으로 제한한다. Azure Speech와 ElevenLabs는 엔진 어댑터와 인증 설정을 확인한 뒤 연결하며, UI에서 지원하지 않는 상태를 활성 옵션처럼 보이지 않게 한다.

### 자막 설정

- 자막 사용 여부
- 상단·중앙·하단·사용자 지정 위치
- 안전 영역 표시
- 폰트
- 글자 크기
- 글자 색상
- 외곽선 색상과 두께
- 배경 색상
- 정렬과 자동 줄바꿈

기존 SubtitleStyle 모델의 위치, 폰트, 크기, 색상, 외곽선, 배경, 사용자 지정 좌표 필드를 우선 재사용한다.

## 적용 범위와 우선순위

설정값은 다음 우선순위로 해석한다.

1. 컷별 예외 설정
2. 프로젝트 기본 설정
3. 엔진·자막 기본값

컷별 예외를 저장할 때는 전체 설정을 복제하지 않고 변경된 필드만 저장한다. 따라서 프로젝트 기본값을 바꿔도 예외로 지정하지 않은 필드는 함께 갱신된다.

## 데이터·API 방향

프로젝트에 다음의 기본 설정을 추가한다.

    ProjectVideoSettings
    ├─ audio
    │  ├─ enabled
    │  ├─ provider
    │  ├─ language
    │  ├─ voice_id
    │  ├─ speed
    │  ├─ volume
    │  └─ pitch
    └─ subtitle
       ├─ enabled
       ├─ style
       ├─ alignment
       ├─ max_lines
       └─ safe_area

제안 API:

- GET /api/projects/{project_id}/video-settings
- PATCH /api/projects/{project_id}/video-settings
- PUT /api/projects/{project_id}/cuts/{cut_id}/video-settings
- POST /api/projects/{project_id}/tts/preview
- POST /api/projects/{project_id}/tts/generate

컷별 설정 PUT은 전체 설정을 복제하지 않고 변경 필드만 저장한다. 빈 객체를 보내면 해당 컷의 예외 설정을 초기화하며, 매니페스트를 만들 때 프로젝트 기본값과 병합한 해석 결과를 컷별 `video_settings`로 기록한다.

TTS 생성은 컷별 작업으로 큐에 등록한다. 각 작업은 내레이션 텍스트, 엔진, 목소리, 속도, 볼륨의 해시를 기준으로 캐시할 수 있어 같은 설정을 반복 생성하지 않는다. 한 컷의 실패가 다른 컷의 음성 생성 작업을 취소하지 않도록 한다.

출력 매니페스트에는 다음을 포함한다.

- 컷별 음성 asset ID
- 컷별 내레이션 텍스트
- 프로젝트 기본 자막 스타일
- 컷별 자막 예외 스타일
- TTS 설정으로 생성된 오디오의 길이와 동기화 정보

## 검증 기준

- 설정 저장 후 새로고침해도 값이 유지된다.
- 상단·중앙·하단·사용자 지정 위치가 미리보기와 매니페스트에 동일하게 반영된다.
- 컷별 예외 설정은 지정한 컷에만 적용된다.
- 출력 비율과 원본 이미지 비율이 어긋나도 이미지가 임의로 잘리지 않는다.
- TTS 생성 중에는 컷별 상태와 전체 진행률을 표시한다.
- 한 컷의 실패가 다른 컷의 작업을 막지 않는다.
- 데스크톱, 태블릿, 390px 모바일에서 가로 넘침·겹침이 없다.
- API, 프론트 단위 테스트, E2E, 렌더 매니페스트 검증을 단계마다 실행한다.

## 현재 구현 범위

현재 화면에서는 프로젝트 기본값을 전체 컷에 적용하거나 선택한 컷에만 예외값을 저장할 수 있다. 컷 예외는 변경된 필드만 보관하고, ‘기본값으로 되돌리기’로 초기화한다. 선택한 컷의 원본 이미지와 자막 위치를 미리보기에서 확인하고, 음성 엔진·언어·목소리·속도·볼륨·피치 및 자막 위치·글꼴·크기·색상·외곽선·배경·안전 영역을 저장한다. 프로젝트 기본값 변경은 예외로 지정하지 않은 컷 필드에 계속 반영된다.

Azure Speech와 ElevenLabs는 엔진 연결 전까지 비활성 옵션으로 표시하며, TTS 미리듣기 버튼은 실제 작업 큐가 연결되는 다음 단계 전까지 비활성 상태로 둔다.
