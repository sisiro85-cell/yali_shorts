# 영상 설정 독립 단계 검증 기록

일자: 2026-09-05
범위: 디자인과 출력 사이에 영상 설정 단계를 추가하고, 설정 저장·라우팅·반응형 화면·기존 주소 호환을 검증

## 구현

- 제작 흐름을 `아이디어 → 대본 → 컷 구성 → 디자인 → 영상 설정 → 출력` 6단계로 확장했다.
- 백엔드 프로젝트 `stage`와 `status`에 `video_settings`를 추가하고 진행률을 85%로 정의했다.
- 정식 프런트 경로를 `/projects/{project_id}/video-settings`로 지정했다.
- 기존 `/projects/{project_id}/design/settings` 주소는 계속 열리도록 라우터 호환 경로로 유지했다.
- 상단 진행 표시, 왼쪽 메뉴, 홈 진행 목록에 영상 설정을 표시했다.
- 디자인 단계의 다음 버튼은 영상 설정으로 이동하고, 이동 전에 모든 컷 이미지가 준비되어야 한다.
- 영상 설정 단계의 다음 버튼은 변경된 설정을 저장한 뒤 출력 단계로 이동한다.
- 디자인·영상 설정의 단계 번호를 `4/6`, `5/6`으로 정렬했다.

## 확인한 사용자 흐름

1. 디자인 단계에서 이미지 전체 생성 상태와 준비 컷을 확인한다.
2. 모든 컷이 준비되면 `영상 설정으로 이동` 버튼이 활성화된다.
3. 영상 설정에서 음성·자막 값을 저장한다.
4. `다음: 출력으로 이동`을 누르면 프로젝트 단계가 `output`으로 저장되고 출력 경로로 이동한다.
5. 1024px, 820px, 620px, 390px 뷰포트에서 가로 넘침이 발생하지 않는다.

## 제한 사항

이번 단계는 영상 설정을 독립 화면과 제작 단계로 분리한 작업이다. 출력 화면의 실제 렌더링, TTS 미리듣기·전체 음성 생성, 업로드 오디오 provider 연결은 기존 계획의 다음 단계에서 계속 구현한다.
