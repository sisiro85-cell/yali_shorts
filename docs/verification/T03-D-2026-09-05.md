# T03-D 검증 기록

일자: 2026-09-05  
범위: 컷별 TTS 작업 등록과 worker 처리

## 구현

- `POST /api/projects/{project_id}/tts/preview`를 추가했다.
- `POST /api/projects/{project_id}/tts/generate`를 추가했다.
- 두 API는 현재 선택된 컷의 내레이션, 활성 버전 ID, 프로젝트 기본값과 컷 예외를 병합한 음성 설정을 작업 payload에 저장한다.
- 같은 컷에 `tts.preview`·`tts.generate`가 queued/running인 동안 새 요청이 오면 중복 작업을 만들지 않고 기존 작업을 반환한다.
- `JobProcessor`가 TTS provider를 호출하고 결과를 오디오 asset으로 저장한다.
- 저장 직전에 컷의 대본·활성 버전·음성 설정이 작업 시점과 같은지 확인해 오래된 결과가 현재 설정을 덮어쓰지 않게 했다.
- TTS 결과는 기존 이미지 상태를 변경하지 않고 `audio_asset_id`만 갱신한다.
- 프런트 API 클라이언트에 `previewTTS`·`generateTTS`를 추가했다.

## 제한 사항

이번 단계의 작업 API는 한 번에 컷 하나를 대상으로 한다. 전체 컷 병렬 생성 batch API는 중복·취소·부분 실패 집계를 별도 단계에서 구현한다. 현재 연결된 실사용 provider는 Edge TTS이며, 업로드 오디오 선택 경로는 다음 단계에서 연결한다.
